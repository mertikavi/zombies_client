# 🧟 Zombies Client - AI Powered Python Game

🎮 **Zombies Client**, tamamen **yapay zeka ile geliştirilmiş** bir Python oyun projesidir.  
Oyunda **üstten bakış açısıyla yaklaşan zombileri vurup hayatta kalmaya çalışıyorsunuz**.  

---

## ✨ Özellikler
- 👁️ **Top-down** kamera görünümü  
- 🧟 Sonsuz sayıda **yaklaşan zombiler**  
- 🔫 Silah & nişangah mekanikleri  
- 🎵 Ses efektleri ve atmosfer müzikleri  
- 🖼️ Özel arka plan ve görseller  

---

## 🚀 Kurulum ve Çalıştırma

### 1. Depoyu klonla
```bash
git clone https://github.com/renardozt/zombies_client.git
cd zombies_client
```

### 2. Gerekli kütüphaneleri yükle
Python ortamında aşağıdaki komutla bağımlılıkları kurabilirsiniz:
```bash
pip install -r requirements.txt
```
*(Eğer `requirements.txt` yoksa, `pygame` ve proje için kullanılan diğer kütüphaneleri yüklemeniz yeterlidir.)*

### 3. Oyunu başlat
```bash
python zombieapocalypse.py
```

## 📂 Proje Yapısı
```

```
